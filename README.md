# عينك - 3ynk

تطبيق Windows محلي بواجهة عربية داكنة قابلة للتخصيص. الخدمة تربط إلى `127.0.0.1` فقط، ولا تفتح LAN أو الإنترنت.

## الوظائف المتاحة

- **التحكم:** لوحة ماوس، مفاتيح ونص عربي/إنجليزي، اختصارات محددة، أزرار الصوت، Task Manager، وأوامر الطاقة مع تأكيد.
- **الشاشة:** اختيار شاشة، معاينة JPEG محلية منخفضة المعدل لتخفيف الحمل، وحفظ لقطة في `Pictures\PC Control Screenshots`.
- **الكاميرا:** معاينة مباشرة محلية من المتصفح بعد إذن المستخدم؛ لا تسجيل ولا رفع أو حفظ تلقائي، وتتوقف المسارات عند مغادرة الصفحة.
- **إضاءة الكمبيوتر:** يدعم التطبيق SignalRGB عبر API المحلية؛ معظم نقاط التحكم تتطلب Pro، ويعرض التطبيق هذا القيد صراحة ويمكن إرسال اسم تأثير مثبت عبر رابط التطبيق. كما يتصل بخادم OpenRGB SDK على `127.0.0.1:6742` لعرض عدد الأجهزة وملفات التعريف وإرسال طلب تحميل ملف تعريف. يتطلب ذلك تثبيت OpenRGB وتشغيل خادم SDK، ويختلف دعم القطع. يمنع التطبيق تحميل ملف تعريف OpenRGB عندما يكتشف SignalRGB يعمل لتفادي تحكم متزامن.
- **الملفات:** مجلدات Desktop وDocuments وDownloads وPictures وVideos الموجودة فقط؛ تصفح وبحث ورفع وتنزيل (حد 16 MB للملف)، إنشاء مجلد وإعادة تسمية ونسخ/نقل الملفات وحذف ملف أو مجلد فارغ بعد التأكيد. لا يسمح بحذف مجلدات غير فارغة.
- **مراقبة الجهاز:** CPU وRAM والأقراص والعمليات الأعلى استخدامًا للذاكرة ووقت التشغيل. GPU والحرارة يظهران «غير متاح» لعدم توفر مصدر موثوق.
- **التطبيقات:** اختصارات قائمة ابدأ التي تشير إلى EXE موجودة؛ يمكن البحث والتثبيت بالمفضلة وتشغيل التطبيق من قائمة موثوقة فقط، مع اختصارات سريعة لإدارة المهام والشاشة والملفات.
- **الشبكة:** Health Check ومدة استجابته، تحديث يدوي ونسخ عنوان الخدمة، واجهات الشبكة وعناوينها، وعدّادات النقل الإجمالية للنظام مع تلميحات حسب حالة الواجهات. الخدمة تبقى على localhost؛ اتصال iPhone/LAN غير مفعّل.
- **الرئيسية:** ترحيب يتغير حسب الوقت مع تاريخ وساعة محليين، اختصارات للأقسام، ملخص حي للمعالج والذاكرة والتخزين وواجهات الشبكة، اقتراح حسب حالة الجهاز، وتشغيل التطبيقات المثبتة. لوحة «حالة الأدوات» تختبر فعليًا واجهات الشاشة والملفات والمراقبة والتطبيقات والشبكة، وتعرض نتيجة كل واجهة وتفاصيلها وزمن الفحص.
- **البحث السريع:** افتح لوحة الأوامر من `Ctrl+K` أو زر البحث للعثور على الأقسام والإجراءات والتطبيقات، مع تنقل بلوحة المفاتيح.
- **الإعدادات والواجهة:** عشرة ثيمات، ألوان تمييز جاهزة ولون مخصص، كثافة، موضع شريط التنقل (يمين/يسار/أعلى/أسفل)، تخطيط بطاقات، وإخفاء البطاقات وإعادة ترتيبها. معاينة حية للثيم، والشريط الجانبي يطوى إلى أيقونات ويتوسع عند المرور أو التنقل بلوحة المفاتيح؛ عند توسعه تُحجز مساحته من المحتوى بدل تغطيته. تغيير اللغة يبدل اتجاه وحركة الانتقال، مع عبارات مرحبة متجددة كل 26 ثانية. حفظ التفضيلات والمفضلة في المتصفح، مع احترام إعداد تقليل الحركة. على الشاشات الصغيرة يتحول التنقل إلى شريط سفلي قابل للسحب، وتتكيف أدوات التحكم والنماذج والجداول والبطاقات للمس والعرض العمودي.

## التشغيل من المصدر

يتطلب Python 3.11 أو أحدث والحزم `mss`, `Pillow`, `psutil`، و`pywin32` على Windows.

```powershell
python app.py
```

يفتح التطبيق `http://localhost:8765` تلقائيًا. إذا كان المنفذ مستخدمًا، يختار منفذ localhost التالي المتاح (حتى 20 منفذًا). لتحديد منفذ بعينه عيّن `PC_CONTROL_PORT` قبل التشغيل. الإيقاف من نافذة العملية عبر Ctrl+C.

## بناء Windows EXE

يحتاج البناء PyInstaller 6.18.0 والحزم المذكورة أعلاه. شغّل من جذر المشروع:

```powershell
python -m PyInstaller --noconfirm --clean --onefile --console --name 3ynk-mobile-20261024c --add-data "web;web" --distpath outputs --workpath work\pyinstaller-3ynk-mobile-20261024c --specpath . app.py
```

الملف الناتج `outputs\3ynk-mobile-20261024c.exe` يضم Python وملفات الواجهة والحزم المكتشفة. شُغّل وتحقق على جهاز التطوير الحالي؛ لم يُختبر على جهاز Windows آخر.

## استخدام الهاتف والاستضافة

الواجهة متجاوبة مع الشاشات الصغيرة، لكن خدمة التحكم مربوطة حاليًا بـ `127.0.0.1` (localhost). لذلك يعمل تصميم الهاتف عند تصغير المتصفح، لكن الهاتف لا يستطيع الوصول إلى خدمة Windows عبر Wi‑Fi بعد. نشر هذا المشروع على Manus وحده لا ينقل خدمة Windows إلى الخادم ولا يمنح الموقع وصولًا إلى الكمبيوتر. يلزم إعداد عميل محلي واتصال آمن قبل تفعيل التحكم من الهاتف أو نشره للاستخدام العام؛ لا تضع هذا المشروع على استضافة عامة على أنه خدمة تحكم جاهزة.

## الاختبارات

```powershell
python -m unittest discover -s tests -v
```

الاختبارات تغطي Health Check، رفض Host/Origin غير مسموح، حصر الأوامر، أمان مسارات الملفات وعملياتها، بيانات المراقبة والشبكة، وحالات تكامل SignalRGB/OpenRGB. لا تنفذ إطفاءً أو ضغطات مفاتيح فعلية أو تغييرات إضاءة.
